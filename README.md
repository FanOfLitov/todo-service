# Todo Service

REST API чтобы отслеживать приоритеты и дедлайны



## стэк

- Java 21
- Spring Boot 3
- Spring Web
- Spring Data JPA
- Hibernate
- H2 Database
- Jakarta Validation
- JUnit 5
- Mockito
- Gradle

## фичи

- создание задачи
- выбрать по айди задачу
- взять все задачи
- фильтр по статусу
- фильтр по приоритету
- обновление статуса
- помечает выполненные задачи
- удалить можно
- входящие запросы и валидация
- Исключения
- сортировка по дедлайну и приоритетам

Задачи отсортированы:

1. Deadline —сначала самые блихкие к дедлайну
2. без дедлайна задачи в конце размещаются
3. приоритеты — HIGH, MEDIUM, LOW

## таблица полей(из тз)

| Field | Type | Description |
|---|---|---|
| id | Long | Generated automatically |
| title | String | Required, maximum 200 characters |
| description | String | Optional, maximum 1000 characters |
| priority | Enum | LOW, MEDIUM, HIGH |
| deadline | LocalDate | Optional |
| status | Enum | TODO, DONE |
| createdAt | LocalDateTime | Generated by the server |

Default priority: `MEDIUM`.

Default status: `TODO`.

## API

### создание задачи

```http
POST /api/tasks
```

пример:

```bash
curl -X POST http://localhost:8080/api/tasks \
-H "Content-Type: application/json" \
-d '{
  "title": "Prepare internship project",
  "description": "Finish REST API",
  "priority": "HIGH",
  "deadline": "2026-10-07"
}'
```

### взятие задачи

```http
GET /api/tasks/{id}
```

пример:

```bash
curl http://localhost:8080/api/tasks/1
```

### все задачи вывести

```http
GET /api/tasks
```

доступные фильтры:

```text
status=TODO|DONE
priority=LOW|MEDIUM|HIGH
```



```bash
curl "http://localhost:8080/api/tasks?status=TODO&priority=HIGH"
```

### Обновление задачи

```http
PUT /api/tasks/{id}
```

### отметка выполнена

```http
PATCH /api/tasks/{id}/done
```

пример:

```bash
curl -X PATCH http://localhost:8080/api/tasks/1/done
```

### удалить задачу

```http
DELETE /api/tasks/{id}
```

пример:

```bash
curl -X DELETE http://localhost:8080/api/tasks/1
```

## HTTP коды статусов

- `200 OK` — successful request
- `201 Created` — task created
- `204 No Content` — task deleted
- `400 Bad Request` — invalid input
- `404 Not Found` — task not found
